✅ Como funciona o fluxo

          

            A ideia central: parar de queimar contas. O que faz a conta durar é o IP de saída — um 4G/LTE de operadora (modem/chip BR ou proxy móvel), que tem trust alto porque é compartilhado por milhares de usuários reais. Você cria a conta no Camoufox pela sua conexão 4G, com o fingerprint já forçado pra Brasil (Porto Alegre), e depois extrai devagar — conta saudável + IP móvel + ritmo lento = dura semanas, não dias.



            O que o app faz por você:

            • Gera o perfil Camoufox com fingerprint BR coerente e estável (timezone/idioma/GPU/WebRTC por perfil)

            • Deixa você apontar cada conta pro seu IP móvel (Contas → Detalhes → Proxy do perfil)

            • Importa a sessão por cookie (sem login novo) ao cadastrar a conta

            • Monitora o status (ativa / em suspensão / banida) e mostra o IP em uso no topo

            • Extrai seguidores/seguindo/posts com o Spider (paralelo + ritmo sustentável) e gera o log por extração pra análise



            ⚠️ O que importa: o IP de saída tem que ser 4G/LTE (não 5G) e coerente com o fingerprint BR. Rodar por um IP estrangeiro ou datacenter queima. Trate cada conta como ativo durável, não descartável.
          

        


        
Configuração inicial


        

          

            • IP móvel 4G/LTE (fator nº 1) — seu modem/chip BR (conexão local) ou um proxy móvel 4G torre-rotativo. 1 IP por conta é o ideal; um IP móvel bom aguenta poucas contas. ❌ Evite datacenter/ISP-estático.

            • E-mails pra criar as contas — cadastre na aba Emails. O código de verificação vem no provedor do e-mail.

            • O fingerprint já sai Brasil (Porto Alegre) automaticamente — não precisa configurar.

          Boas práticas para a conta durar:

          • IP móvel 4G/LTE (não 5G — pool pequeno; ❌ não datacenter), 1 IP por conta quando der. Um IP móvel bom aguenta poucas contas.

          • Fingerprint BR coerente — já forçado (Porto Alegre). Só use IP de saída também BR (o modem/chip ou proxy BR), senão fica incoerente.

          • Ritmo sustentável (~200-300 req/dia): a conta dura semanas; o volume vem de várias contas em paralelo, não de blastar uma.

          • Trate cada conta como ativo durável — pare de tratar como descartável.

          • Extração = método Web (o App/instagrapi loga de novo = queima mais rápido).

📡 Modem 4G — rotação de IP

          
        

        
carregando…

        

          

            
            
          

          

            
            
          

          

            
            
          

        

        

          
          
          
Os dois renovam o IP; a troca de modo é bem mais rápida e termina com o modem travado em 4G puro.

        

        
        

          🚨 Feche WhatsApp Web / Instagram pessoal / Facebook antes de rodar. São todos Meta: a rotação
          troca o IP do PC inteiro, a sessão pessoal salta de IP no meio (já causou bloqueio aqui) e a Meta passa a ver
          sua conta real e as de automação no mesmo IP. Para separar de verdade, proxy por perfil (aba Contas).

          ⚠️ A rotação derruba a saída de todos os perfis por alguns segundos (é a conexão do PC inteiro) — por isso ela é serializada: uma por vez.
          E este modem não tem um IP só: a operadora faz CGNAT e responde de 3-4 IPs ao mesmo tempo. O que a rotação garante é que o conjunto seja renovado, não "1 conta = 1 IP".

🛡️ Guia de proxies — o fator nº 1 contra detecção

        O Instagram pesa MUITO a reputação do IP na criação da conta. O tipo de proxy decide se a conta nasce limpa ou já sinalizada (captcha/telefone de cara).

        
Tipo de proxy — do pior ao melhor para CRIAR conta

        
    
          
  • ❌ Datacenter — bloqueado quase sempre no signup. Não use para criar.
    • 
          
  • ⚠️ ISP-estático compartilhado (ex.: listas "20/100 proxies" da Webshare) — IPs fixos divididos entre vários clientes; queimam rápido. Servem só para aquecer conta já criada, não para nascer.
    • 
          
  • ✅ Residencial rotativo — IPs de provedores domésticos reais. Bom.
    • 
          
  • ⭐ Móvel (4G/LTE) — padrão-ouro. IPs de operadora sob CGNAT (compartilhados com milhares de usuários reais) → o IG não consegue punir o IP sem punir gente legítima. 4G, não 5G: o pool 5G é pequeno e fácil de fingerprintar.
    • 
        


        
Como conseguir proxy móvel

        
    
          
  • DIY com chip BR (melhor custo-benefício): app iProxy.online (ou Proxidize) num Android com chip Vivo/Claro/TIM. IP genuinamente brasileiro, barato, 1 IP por aparelho — ótimo para volume baixo.
    • 
          
  • Dedicado alugado: modem 4G/LTE só seu (~US$30–120/mês). Menos trabalho.
    • 
          
  • Pools (Soax / IPRoyal / Smartproxy): IPs móveis/residenciais por GB — cuidado, muitos já foram usados à exaustão no IG.
    • 
        


        
Boas práticas

        
    
          
  • 1 IP limpo por conta (sticky na criação — não rotacionar no meio do cadastro).
    • 
          
  • Rotacione o IP entre uma conta e outra (modo avião liga/desliga no celular, ou via API do provedor). O IP é compartilhado: a próxima rotação já dá um IP novo do pool — não precisa trocar o chip/plano.
    • 
          
  • Um país só, coerente com a persona. Configure o País-alvo em Contas → Limites — o app passa a usar só proxies desse país (persona BR ↔ IP BR).
    • 
          
  • Ritmo lento e poucas contas por IP/dia.
    • 
          
  • Evite datacenter e ISP-estático compartilhado para criar.
    • 
        


        
Sair pela sua própria conexão (sem proxy)

        É o padrão: o perfil sem proxy sai pelo modem 4G ligado neste PC. O geoip está fixado em Porto Alegre/pt-BR, então isso só é coerente com um IP de saída brasileiro (o modem 4G daqui) — o IP de casa (banda larga) não serve. Quem escolhe a conexão de cada perfil é a aba Contas (campo "Proxy do perfil": vazio = modem).

Spider

          
Extrai dados do Instagram usando um perfil JÁ LOGADO (a conta do perfil faz as requisições). Tipos: seguidores, seguindo e posts.

        

      


      

        

          
          
        

        

          
          

          
Use contas de scraping descartáveis já logadas — não use suas contas boas (raspar queima conta). Marcar 2+ abre a escolha: alvos diferentes (recomendado — cada conta no seu alvo, em paralelo) ou mesmo alvo com handoff seguro (cada conta vai até ~1,5M e passa pra próxima).
↪ Trocar de conta e continuar: se uma run caiu, marque 1 conta nova aqui e clique Continuar de onde parou — segue do mesmo ponto com a conta fresca (faça logo: o cursor expira com o tempo).

          
          
          

        

        

          
          
          
          
🛟 Handoff: uma conta por vez extrai até ~1,5M (abaixo do teto de ~1,6M onde a conta cai), segue o alvo e passa o cursor pra próxima conta marcada. Use contas descartáveis. Se houver só 1 conta, roda no padrão (sem corte).

        

        

          
          
          
        

        

          
          
        

        

          
          
          

        

        

          

            
            
          

          

            
            
          

        

        

          
          
          
Cada requisição = ~50 itens. O limite por hora é o que evita a suspensão — escolha pela confiança da conta: descartável/nova aguenta pouco; conta antiga/aquecida aguenta muito (é o segredo do volume alto numa conta só). Inclui jitter ±40% + pausas de proteção.

O descanso extra entra depois que todas passaram — a frota inteira para por esse tempo antes de recomeçar pela primeira. Use 0 para emendar as voltas.

      


      
      

        
Deixar de seguir

        

          O Instagram limita cada conta a seguir 7.500 perfis. Sem desfazer follows a campanha
          trava nesse teto — por isso o unfollow não é opcional a longo prazo, é o que mantém espaço.
        

        

        

          

            
            
          

          

            
            
          

        

        
        

          🔒 Só desfaz o que o app seguiu com esta conta — follows que você fez na mão nunca são tocados.
          A whitelist abaixo protege contas específicas para sempre.

5 · Comportamento humano — o que a conta faz além de seguir

        

          🧬 Medido no banco em 21/08: as contas tinham 6.894 ações e um verbo só (seguir); 99,9% dos intervalos
          caíam entre 7 e 30s; e seguiam às 2h da manhã no mesmo ritmo das 15h. Pior: o pedido de follow declara
          container_module=profile — uma tela que a sessão nunca abria. Tudo o que é padronizado é lido como robô.
          Estes ajustes quebram esse padrão sem mudar como se segue.
        

        
        

          

            
            
            
É o que torna verdadeira a origem que o pedido já declara.

          

          

            
            
            
O resto usa a leitura leve (~50 KB em vez de ~3 MB). É este número que come o plano de 30 GB — e a curtida depende dele.

          

        

        

          

            
            
            
Curte clicando na interface, então quem monta o pedido é o próprio Instagram. Só vale quando a página foi aberta.

          

          

            
            
            
Controla custo, nunca existência: em 0% a conta continua agindo em toda volta, só que sempre pelas ações baratas (espiar um perfil sem seguir, buscar — ~50 KB). Acima disso, a primeira ação pode ser feed (~2,5 MB) ou explorar (~4 MB).

          

        

        

          
          
          

            As ações ficam no fim da pausa, não no começo — a conta volta fazendo algo, em vez de voltar seguindo.
            A segunda é sempre barata (~50 KB) e é a última coisa antes do follow, para o follow parecer consequência
            do que se estava olhando. Seguir → parar → seguir é padrão óbvio.
          

        

        

          
          
          

        

        
        

          

            
            
          

          

            
            
            
Sequência longa é sinal de bot. 2 a 5 é o que uma pessoa faz mexendo numa lista.
